AdaBoost & Gradient Boosting

Boosting builds an ensemble sequentially: each weak learner focuses on what the previous ones got wrong. AdaBoost does it by re-weighting samples; Gradient Boosting does it by fitting the negative gradient of the loss (residuals for squared error). Understand this page and XGBoost/LightGBM/CatBoost are just engineering on top.

🎯 Say this in the interview

“Boosting combines weak learners sequentially to reduce bias. AdaBoost reweights the training samples — misclassified points get more weight — and combines stumps with weights based on their error; it's equivalent to forward stagewise fitting of exponential loss. Gradient boosting generalises this to any differentiable loss: start with a constant, then at each step fit a small regression tree to the negative gradient (pseudo-residuals) of the loss with respect to the current predictions, and add it scaled by a learning rate. Key knobs are learning rate, number of trees (with early stopping), tree depth/leaves, subsampling and min samples per leaf. Unlike random forests, more trees can overfit.”

The core idea

🧒 In plain English

A student takes a mock test, then studies only the questions they got wrong, takes another test, studies those mistakes, and so on. Each round is a small, targeted improvement. The final knowledge is the sum of all the rounds — but study too long on the same mock paper and you just memorise its answers (overfitting).

∑ Additive model built stage-wise
$$F_M(x)=F_0(x)+\sum_{m=1}^{M}\eta\,h_m(x)$$

Each \(h_m\) is a weak learner (shallow tree) chosen to most reduce the loss given \(F_{m-1}\); η is the learning rate (shrinkage).

AdaBoost (classification)

  1. Initialise sample weights \(w_i=1/n\); labels \(y_i\in\{-1,+1\}\).
  2. For m = 1…M: fit a weak learner \(h_m\) (usually a depth-1 stump) on the weighted data.
  3. Weighted error \(\varepsilon_m=\sum_i w_i\,\mathbb 1[h_m(x_i)\ne y_i]\).
  4. Learner weight \(\alpha_m=\tfrac12\ln\frac{1-\varepsilon_m}{\varepsilon_m}\) (better learners count more; ε = 0.5 → α = 0).
  5. Update \(w_i\leftarrow w_i\,e^{-\alpha_m y_i h_m(x_i)}\), then normalise — misclassified points get heavier.
  6. Final: \(H(x)=\operatorname{sign}\big(\sum_m\alpha_m h_m(x)\big)\).

AdaBoost = gradient boosting with exponential loss \(e^{-yF(x)}\). That loss punishes misclassified points exponentially, so AdaBoost is sensitive to label noise and outliers.

Gradient boosting (Friedman)

∑ Algorithm
  1. \(F_0(x)=\arg\min_c\sum_iL(y_i,c)\) — the mean for squared error, the log-odds of the base rate for log-loss.
  2. For m = 1…M:
    • Pseudo-residuals: \(r_{im}=-\Big[\frac{\partial L(y_i,F(x_i))}{\partial F(x_i)}\Big]_{F=F_{m-1}}\)
    • Fit a regression tree \(h_m\) to \(\{(x_i,r_{im})\}\) → leaf regions \(R_{jm}\).
    • Optimal leaf values: \(\gamma_{jm}=\arg\min_\gamma\sum_{x_i\in R_{jm}}L(y_i,F_{m-1}(x_i)+\gamma)\).
    • Update \(F_m(x)=F_{m-1}(x)+\eta\sum_j\gamma_{jm}\mathbb 1[x\in R_{jm}]\).

For squared error \(L=\tfrac12(y-F)^2\) the negative gradient is exactly the residual \(y-F\): “fit the residuals”. For log-loss it's \(y-p\). Gradient boosting = gradient descent in function space.

Regularising a booster

  • Shrinkage (learning rate η): smaller steps → each tree corrects less → need more trees, but generalises better. η and n_estimators trade off — lower η, then use early stopping to find the tree count.
  • Tree complexity: max_depth (3–8) or max_leaf_nodes; min_samples_leaf. Depth d allows interactions of order d.
  • Stochastic gradient boosting: subsample rows (0.5–0.9) per tree, and columns (in XGBoost/LightGBM) — reduces variance and speeds up.
  • Early stopping: stop when validation loss hasn't improved for k rounds (n_iter_no_change / early_stopping_rounds).
  • Penalties on leaf weights/count (XGBoost λ, α, γ) — see next page.

A tuning recipe that works

  1. Fix a moderate learning rate (0.05–0.1) and use early stopping to pick n_estimators.
  2. Tune tree structure: max_depth / num_leaves and min_samples_leaf (biggest impact).
  3. Tune randomness: subsample, colsample.
  4. Tune regularisation (λ, α, γ).
  5. Lower the learning rate (e.g. ÷5), raise the round budget, re-run early stopping for the final model.

Use random search or Bayesian optimisation (Optuna) rather than full grids; always evaluate on a proper CV scheme.

Interview questions

What is boosting and how does it differ from bagging?

Boosting trains weak learners sequentially, each focusing on the errors of the current ensemble, and combines them with weights — mainly reducing bias. Bagging trains strong learners independently on bootstrap samples and averages them — mainly reducing variance. Boosting is sequential and can overfit with too many rounds; bagging is parallel and doesn't.

Explain how gradient boosting works.

Initialise with a constant minimising the loss. Repeatedly compute pseudo-residuals = negative gradient of the loss w.r.t. current predictions, fit a small regression tree to them, set optimal leaf values, and add the tree scaled by the learning rate. It's gradient descent in function space; for squared error the pseudo-residuals are the ordinary residuals.

Why “gradient” boosting? What is the gradient taken with respect to?

With respect to the model's predictions F(xᵢ) for each training point, not the tree parameters. The vector of negative gradients is the steepest-descent direction in prediction space; each tree approximates that direction as a function of x so it generalises to new points.

How does AdaBoost work?

Start with uniform sample weights; fit a weak learner; compute its weighted error ε and weight α = ½ ln((1−ε)/ε); increase weights of misclassified samples by e^{α} and decrease the others, normalise; repeat. The final classifier is the sign of the α-weighted vote. It minimises exponential loss stage-wise.

Why is AdaBoost sensitive to outliers?

Exponential loss grows exponentially with the negative margin, so persistently misclassified points (mislabelled or outliers) get ever-larger weights and the ensemble contorts itself to fit them. Gradient boosting with log-loss or Huber loss is more robust.

What is the role of the learning rate in boosting?

It scales each tree's contribution (shrinkage). Lower values make each step smaller, requiring more trees but reducing overfitting and usually improving test performance. Tune it together with the number of trees via early stopping.

Can gradient boosting overfit? How do you prevent it?

Yes — with too many rounds, deep trees or a large learning rate it fits noise. Prevent with early stopping on a validation set, lower learning rate, shallower trees / fewer leaves, min samples per leaf, row and column subsampling, and L1/L2 penalties on leaf weights.

Why are shallow trees used as base learners in boosting?

Boosting reduces bias by adding many small corrections; each learner only needs to be slightly better than chance. Shallow trees are low variance, fast, and depth controls the maximum interaction order. Deep trees would overfit quickly and make the sequential correction noisy.

What is the initial prediction F₀ for regression and for binary classification?

The constant minimising the loss: the mean of y for squared error (median for absolute error) and the log-odds of the positive rate, log(p/(1−p)), for log-loss.

What is stochastic gradient boosting?

Friedman's variant: each tree is fit on a random subsample of rows (without replacement, e.g. 50–80%). It injects randomness that reduces variance and correlation between trees, speeds training, and typically improves generalisation. Column subsampling extends the idea.

Gradient boosting vs Random Forest: which handles noisy data better and why?

Random Forest — averaging independent deep trees is robust, and adding trees doesn't overfit. Boosting keeps fitting residuals, which on noisy labels are largely noise, so it needs careful regularisation and early stopping.

How do you choose the number of trees?

Early stopping: monitor a validation metric each round and stop when it hasn't improved for k rounds (e.g. 50), keeping the best iteration. With CV, take the average best iteration across folds for the final refit on all data.

How can boosting produce prediction intervals?

Train models with quantile loss at, say, α = 0.05 and 0.95 (GradientBoostingRegressor(loss="quantile"), LightGBM objective="quantile"), or use conformal prediction on top of any regressor for distribution-free coverage guarantees.
