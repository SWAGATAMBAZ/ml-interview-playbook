Bagging (bootstrap aggregating)

Train the same model many times on random re-samples of the data and average the results. It's the simplest ensemble, the foundation of Random Forest, and the cleanest way to understand variance. Interviewers ask why it works, why it needs unstable models, what out-of-bag means and how it differs from boosting.

🧒 In plain English

Imagine asking a very opinionated friend to estimate house prices. They've seen only the houses in your dataset, and they latch onto every quirk — so if you'd shown them a slightly different set of houses, they'd give quite different answers. Now clone that friend 200 times, show each clone a different random re-sample of the houses, and average their answers. Each clone's quirks point in different directions and cancel out; what they agree on survives.

The “random re-sample” is a bootstrap: pick rows at random with replacement, as many as the original dataset has. Some rows appear twice, about a third don't appear at all.

How it works, step by step

  1. Bootstrap: draw n rows with replacement from the n training rows. Repeat to get B different samples.
  2. Train one copy of the base model (usually a deep decision tree) on each sample, independently — in parallel.
  3. Aggregate: average the predictions (regression) or take a majority vote / average the probabilities (classification).
  4. Validate for free: each row was left out of about 37% of the samples; predicting it with only those models gives the out-of-bag (OOB) estimate.
🎯 Say this in the interview (30 seconds)

“Bagging trains B copies of a model on bootstrap samples and averages them. Averaging B predictors with variance σ² and pairwise correlation ρ gives variance ρσ² + (1 − ρ)σ²/B, so it cuts variance without adding bias — it helps unstable, high-variance learners like deep trees and does almost nothing for stable ones like linear regression. Each bootstrap leaves out about 37% of rows, which gives a free out-of-bag error estimate. Random Forest is bagging plus random feature subsets to lower ρ further.”

How it works — from layman to advanced

Level 1 · Plain English

Any model trained on data has two kinds of error: it can be systematically wrong (bias — too simple to capture the pattern) or erratic (variance — it would change a lot if you gave it different data). A deep decision tree has little bias and a lot of variance. Bagging attacks only the second kind: by averaging many versions of the model trained on different-looking data, the erratic part cancels, the systematic part stays.

Level 2 · The algorithm

  1. For b = 1…B: draw bootstrap sample \(D_b\) (n rows, with replacement); fit \(\hat f_b\) on \(D_b\).
  2. Regression: \(\hat f(x)=\frac1B\sum_b\hat f_b(x)\). Classification: majority vote, or better, average the predicted probabilities (“soft voting”).
  3. OOB: for each row i, average only the models whose bootstrap sample did not contain i; compute the error over all rows.

Level 3 · Worked examples by hand

One bootstrap sample. Training rows A, B, C, D, E, F. Draw 6 times with replacement: B, D, D, A, F, B. Unique rows: A, B, D, F (4 of 6). Rows C and E are out-of-bag for this model, so they can test it. On average a row is left out with probability \((1-\tfrac1n)^n\to e^{-1}\approx0.368\), so each sample contains about 63.2% of the unique rows.

Averaging three trees. For one house, three bagged trees predict ₹52 L, ₹61 L and ₹49 L. Bagged prediction = (52 + 61 + 49)/3 = ₹54 L. A classifier with three trees giving P(default) = 0.9, 0.4, 0.35: hard vote = 1 of 3 say “default” → not default; soft vote = average 0.55 → default. Soft voting uses confidence and is usually better.

Level 4 · What advanced interviewers probe

  • Bias is (almost) unchanged. The average of identically distributed estimators has the same expectation. Strictly, bootstrapping trains each model on ~63% unique rows, so members are slightly weaker; the bagged model's bias is close to one model's bias on that much data.
  • Instability is the requirement. Breiman's point: bagging helps when small data changes cause large prediction changes (trees, unpruned; neural nets; kNN with small k is surprisingly stable to bootstrap). For stable learners (linear regression, Naive Bayes) the members are near-identical (ρ ≈ 1) and nothing improves — it can even hurt slightly.
  • OOB vs cross-validation: OOB is nearly free and close to leave-one-out-style estimates, slightly pessimistic for small B (each row is predicted by only ~37% of members). It's invalid with time-ordered or grouped data, because bootstrap rows aren't independent of OOB rows.
  • Bagging and smoothing: averaging step functions produces a smoother function — bagged trees approximate a smooth regression better than any single tree can.
  • Classification subtlety: majority voting can make a classifier worse if each member is worse than chance on a region; soft voting with probabilities is safer.
  • Imbalance: balanced bagging draws each bootstrap sample with equal numbers of each class (undersampling inside each bag), a strong baseline for rare-event detection.
  • .632 bootstrap: estimates error as 0.368 × training error + 0.632 × OOB error to correct OOB's pessimism.

Must-know points for interviews

  • Reduces variance, not bias → use low-bias, high-variance base learners (deep trees).
  • Variance of the average: ρσ² + (1 − ρ)σ²/B. More members shrink the second term; only decorrelation shrinks the first.
  • About 63.2% unique rows per bootstrap; ~36.8% out-of-bag → free validation estimate.
  • Members are trained independently → embarrassingly parallel.
  • More members never overfit; the error plateaus.
  • Works with any model, but only helps unstable ones.
  • Random Forest = bagging + random feature subsets at each split.

Interview questions

What is bagging?

Bootstrap aggregating: train the same learning algorithm on B bootstrap samples (n rows drawn with replacement) and combine their predictions by averaging (regression) or voting/averaging probabilities (classification). It reduces variance and is the basis of Random Forest.

Why does averaging reduce variance? Give the formula.

For B identically distributed predictors with variance σ² and pairwise correlation ρ, Var(average) = ρσ² + (1 − ρ)σ²/B. Independent errors (ρ = 0) shrink by 1/B; correlated ones leave a floor of ρσ². Bias stays that of a single member because the expectation of an average equals the common expectation.

Why does bagging not help linear regression?

Linear regression is a stable, low-variance estimator: bootstrap samples produce almost the same coefficients, so the members are highly correlated (ρ ≈ 1) and their average equals any one of them. Bagging helps only when the learner is unstable — when small changes in data cause large changes in the fitted model.

What fraction of rows appears in a bootstrap sample?

Each row is missed with probability (1 − 1/n)ⁿ → e⁻¹ ≈ 0.368, so about 63.2% of the unique rows appear (some several times) and 36.8% are out-of-bag.

What is the out-of-bag error and when can't you use it?

For each row, predict using only the members whose bootstrap sample didn't contain it, then compute the error across rows — a validation estimate with no hold-out set, close to cross-validation. It's invalid when rows aren't independent: time series (future rows help predict past ones) and grouped data (other rows of the same entity are in-bag).

How is Random Forest different from bagged decision trees?

Random Forest adds a random subset of candidate features at every split. Bagged trees still tend to use the same dominant features near the root, so they're correlated; per-split feature sampling decorrelates them, lowering the ρσ² floor of the ensemble variance.

Bagging vs boosting — which for noisy labels, and why?

Bagging. Its members are trained independently on random samples and averaged, so mislabelled points affect only some members and get outvoted. Boosting focuses later learners on hard points — which include mislabelled ones — so it can chase noise (AdaBoost's exponential loss is especially sensitive).

Hard voting vs soft voting?

Hard voting counts each member's predicted class; soft voting averages predicted probabilities and thresholds the average. Soft voting uses confidence, usually performs better, and gives probabilities — but requires members that output reasonably calibrated probabilities.

Does adding more bagged models ever hurt?

Not in expected accuracy: the error converges as B grows, so extra members only cost training time, memory and latency. In practice watch the OOB curve and stop when it flattens.

What are pasting, random subspaces and random patches?

Pasting samples rows without replacement; random subspaces give each member a random subset of features (all rows); random patches sample both rows and features. They are different ways to make ensemble members diverse, useful for high-dimensional data or very large datasets.

Why do bagged trees produce smoother predictions than a single tree?

Each tree is a step function with thresholds at slightly different places (different bootstrap samples). Averaging many step functions with jittered breakpoints approximates a smooth curve, reducing the abrupt jumps that make a single tree's predictions noisy.

How would you use bagging for a highly imbalanced problem?

Balanced bagging: draw each member's sample with all (or a bootstrap of) minority cases plus an equal-sized random sample of the majority, train, and average. Each member sees a balanced problem while the ensemble still uses most majority data overall. Evaluate with PR-AUC and tune the threshold; recalibrate probabilities if they're needed as probabilities.
