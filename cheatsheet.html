Assumptions at a glance

Model / testKey assumptions
Linear regressionLinearity; independent errors; homoscedasticity; normal errors (for inference); no perfect multicollinearity; exogeneity
Logistic regressionLinearity in the log-odds; independent observations; little multicollinearity; no extreme outliers; enough events per variable
Naive BayesFeatures conditionally independent given the class; (Gaussian NB) normal features per class
LDA / QDAGaussian classes; LDA: shared covariance (QDA: class-specific)
kNNNearby points share labels (smoothness); meaningful distance metric; scaled features
SVMClasses separable (after kernel mapping) with a margin; scaled features
Decision trees / ensemblesFew: rows i.i.d.; axis-aligned splits can approximate the function
K-meansSpherical, similar-size, similar-density clusters; K known; Euclidean geometry
GMMData from a mixture of Gaussians
PCALinear structure; variance = information; scaled features
ARIMAStationarity after differencing; linear dependence on past values/errors; white-noise residuals
t-testIndependent samples; approximately normal means (CLT); Welch handles unequal variances
χ² testIndependent observations; expected counts ≥ 5 per cell
A/B testRandom assignment; stable unit treatment (no interference); consistent measurement; fixed horizon (no peeking)

Must-know formulas

Regression

\(\hat\beta=(X^TX)^{-1}X^Ty\) · Ridge \((X^TX+\alpha I)^{-1}X^Ty\)
\(R^2=1-\frac{SSE}{SST}\) · \(R^2_{adj}=1-(1-R^2)\frac{n-1}{n-p-1}\)
VIF \(=\frac{1}{1-R_j^2}\)

Classification

\(\sigma(z)=\frac1{1+e^{-z}}\) · log-loss \(-[y\log p+(1-y)\log(1-p)]\)
Precision \(\frac{TP}{TP+FP}\) · Recall \(\frac{TP}{TP+FN}\) · F1 \(\frac{2PR}{P+R}\)
Odds ratio \(e^{w}\)

Trees & boosting

Gini \(1-\sum p_k^2\) · Entropy \(-\sum p_k\log_2p_k\)
XGB leaf \(w^*=-\frac{G}{H+\lambda}\) · gain \(\frac12[\frac{G_L^2}{H_L+\lambda}+\frac{G_R^2}{H_R+\lambda}-\frac{G^2}{H+\lambda}]-\gamma\)
Bagging variance \(\rho\sigma^2+\frac{1-\rho}{B}\sigma^2\)

Unsupervised

K-means \(J=\sum_k\sum_{x\in C_k}\lVert x-\mu_k\rVert^2\)
Silhouette \(\frac{b-a}{\max(a,b)}\)
PCA: eigenvectors of \(\Sigma\); explained var \(\lambda_j/\sum\lambda\)

Statistics

SE \(=\sigma/\sqrt n\) · CI \(\bar x\pm z\,\sigma/\sqrt n\)
Two-prop z \(\frac{\hat p_B-\hat p_A}{\sqrt{\hat p(1-\hat p)(1/n_A+1/n_B)}}\)
Sample size \(n\approx16\sigma^2/\delta^2\) per group

Bias–variance & drift

\(E[(y-\hat f)^2]=\text{Bias}^2+\text{Var}+\sigma^2\)
PSI \(=\sum(A-E)\ln\frac AE\): <0.1 ok, >0.25 alert
Bayes \(P(A|B)=\frac{P(B|A)P(A)}{P(B)}\)

Scaling & encoding quick rules

  • Scale: linear/logistic (regularised or GD), SVM, kNN, K-means, PCA, neural nets. Don't need to: trees, RF, GBMs, Naive Bayes.
  • Encode: one-hot (low cardinality, linear models), ordinal (ordered or trees), target encoding with cross-fitting (high cardinality), native categorical (LightGBM/CatBoost).
  • Missing: median + indicator; iterative imputation; native NaN in boosters. Always fit inside the pipeline.
  • Imbalance: PR-AUC; class weights; threshold tuning; resampling in training folds only.

Interview-day checklist

  • For every answer: definition → intuition → maths (one line) → when it breaks → practical example.
  • Always mention trade-offs and how you'd validate (“I'd check with CV / an A/B test”).
  • Tie models to business outcomes and metrics.
  • Have 2–3 project stories (STAR) covering: messy data, a model that failed and why, a production/monitoring lesson, impact in numbers.
  • Coding: clarify, write simple correct code, test on a tiny example, discuss complexity.
  • Ask clarifying questions in case/design rounds before proposing models.
