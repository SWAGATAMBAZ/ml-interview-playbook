How ML / DS interviews are structured

Most loops test the same five areas — statistics & probability, machine learning, coding (Python/SQL), product/business sense and behavioural — and ML-engineering loops add system design and production questions. Monitoring and drift come up in almost every MLOps screen. This playbook covers the ML, statistics, Python-coding and production parts; for SQL and DSA use the sister sites linked in the sidebar.

How to answer any “explain model X” question

1

Definition & intuition

One sentence on what it does, one plain-English analogy.

2

How it learns

Objective/loss and the optimisation or algorithm (one formula).

3

Assumptions & failure modes

When it breaks and how you'd detect it.

4

Knobs

The 2–3 hyperparameters that matter and their effect on bias/variance.

5

Practice

A real use case, how you'd evaluate it, and what you'd compare it against.

About the in-browser Python

Labs use Pyodide (CPython compiled to WebAssembly) running in a background worker, so the page stays responsive. The first run downloads the runtime and packages (~20–30 MB, then cached by your browser). NumPy, pandas, scikit-learn, SciPy, statsmodels, matplotlib, XGBoost and LightGBM are available. Your code and progress are saved locally in this browser only.
