Linear regression

Predict a continuous target as a weighted sum of features. It is simple, but interviewers use it to probe whether you really understand loss functions, optimisation, assumptions, diagnostics, multicollinearity and inference. Know this page cold.

🎯 Say this in the interview (30 seconds)

“Linear regression models the target as \(\hat y = \beta_0 + \beta_1x_1 + \dots + \beta_px_p\). We choose the coefficients that minimise the sum of squared residuals (OLS), which has a closed-form solution \(\hat\beta = (X^TX)^{-1}X^Ty\) or can be found by gradient descent. Under the Gauss–Markov assumptions — linearity, independent errors, constant error variance, no perfect multicollinearity, and errors with zero mean — OLS is the best linear unbiased estimator; adding normal errors gives valid t-tests and confidence intervals. I check the assumptions with residual plots, Q-Q plots, VIF, Breusch–Pagan and Durbin–Watson, and I regularise with Ridge or Lasso when there are many or correlated features.”

Intuition

🧒 In plain English

Plot house size against price and draw the straight line that sits “closest” to all the dots. “Closest” means the vertical gaps (residuals) between dots and line, squared and added up, are as small as possible. The slope tells you how many rupees each extra square foot adds, holding everything else fixed.

model

Linear in parameters

“Linear” refers to the coefficients, not the features. \(y=\beta_0+\beta_1x+\beta_2x^2\) is still linear regression.

loss

Squared error

Squaring makes the loss smooth and convex (one global minimum) and equals maximum likelihood under Gaussian noise — but it also makes OLS sensitive to outliers.

output

Conditional mean

OLS estimates \(E[y\mid x]\). If you need the median or a quantile, use MAE / quantile regression instead.

The maths you need to explain

1 · Model and loss

∑ Formulation
$$\hat y = X\beta,\qquad X\in\mathbb R^{n\times(p+1)}\ \text{(first column of 1s for the intercept)}$$ $$J(\beta)=\frac1n\sum_{i=1}^n (y_i-\hat y_i)^2 = \frac1n\lVert y-X\beta\rVert^2$$

2 · Closed form (normal equation)

Set the gradient to zero: \(\nabla_\beta J = -\tfrac2n X^T(y-X\beta)=0 \Rightarrow X^TX\beta = X^Ty\), so

∑ Normal equation
$$\hat\beta=(X^TX)^{-1}X^Ty$$

Geometrically, \(X\hat\beta\) is the orthogonal projection of \(y\) onto the column space of \(X\): residuals are perpendicular to every feature (\(X^Te=0\)). Consequences: residuals sum to zero (with an intercept) and the fitted line passes through \((\bar x,\bar y)\).

Cost: forming \(X^TX\) is \(O(np^2)\) and inverting it \(O(p^3)\). Fine for \(p\) up to a few thousand; for huge \(p\) or streaming data use (stochastic) gradient descent. In practice libraries solve via QR or SVD (more numerically stable than inverting), and if \(X^TX\) is singular (perfect collinearity or \(p>n\)) the pseudo-inverse or Ridge is used.

3 · Gradient descent

∑ Update rule
$$\beta \leftarrow \beta - \eta\,\nabla J = \beta + \frac{2\eta}{n}X^T(y-X\beta)$$

Batch GD uses all rows per step; SGD one row; mini-batch a few dozen to a few hundred. Feature scaling matters a lot for GD (elongated loss contours → zig-zagging), but not for the closed form.

Gradient descent on a 1-D loss
Too small η crawls, too large η oscillates or diverges. For this quadratic, η > 1 diverges because each step multiplies the error by (1 − 2η).

4 · Why squared error = maximum likelihood

If \(y_i = x_i^T\beta + \varepsilon_i\) with \(\varepsilon_i\sim\mathcal N(0,\sigma^2)\) i.i.d., the log-likelihood is \(-\tfrac{n}{2}\log(2\pi\sigma^2)-\tfrac1{2\sigma^2}\sum(y_i-x_i^T\beta)^2\). Maximising it over \(\beta\) is exactly minimising the sum of squared errors. (Laplace noise → MAE; this is a favourite follow-up.)

5 · Variance of the estimates

\(\operatorname{Var}(\hat\beta)=\sigma^2(X^TX)^{-1}\), estimated with \(\hat\sigma^2=\tfrac{\text{RSS}}{n-p-1}\). Standard errors are the square roots of the diagonal. When features are highly correlated, \(X^TX\) is near-singular, its inverse explodes and so do the standard errors — that is multicollinearity in one line.

⚠️ Common trap

“The features (or y) must be normally distributed” is wrong. The assumption is about the errors (residuals), and it only matters for inference. Skewed features are fine; skewed residuals are what you check.

💬 Gauss–Markov theorem

Under linearity, exogeneity, homoscedasticity, no autocorrelation and full rank (no normality needed), OLS is BLUE — the Best (lowest-variance) Linear Unbiased Estimator. Normality is added only for exact small-sample t and F tests.

Interpreting coefficients & inference

  • \(\beta_j\): expected change in y for a one-unit increase in \(x_j\), holding other features constant. With correlated features that “holding constant” is unrealistic, which is why interpretations get shaky.
  • Log transforms: log(y) ~ x → a unit increase in x changes y by ≈ \(100\beta\)%; y ~ log(x) → a 1% increase in x changes y by \(\beta/100\); log–log → \(\beta\) is an elasticity.
  • t-test per coefficient: \(t=\hat\beta_j/\text{SE}(\hat\beta_j)\), H₀: \(\beta_j=0\). F-test: are all slopes jointly zero?
  • Dummy variable trap: one-hot encoding k categories with an intercept → drop one level (it becomes the baseline), or perfect collinearity.
  • Standardised coefficients (after scaling features) allow comparing importance across features with different units.
  • Statistical significance ≠ practical importance ≠ causality.

R², adjusted R² and error metrics

∑ Definitions
$$R^2 = 1-\frac{\text{RSS}}{\text{TSS}} = 1-\frac{\sum (y_i-\hat y_i)^2}{\sum (y_i-\bar y)^2}\qquad R^2_{adj}=1-(1-R^2)\frac{n-1}{n-p-1}$$
  • R² = share of variance in y explained. It never decreases when you add a feature (even pure noise) on training data. Adjusted R² penalises extra features and can go down.
  • R² can be negative on a test set (model worse than predicting the mean).
  • Use RMSE (same units as y, penalises large errors), MAE (robust, median-oriented), MAPE (relative, breaks near y = 0). See Evaluation metrics.
  • A high R² doesn't mean assumptions hold, and a low R² can still give useful, significant coefficients (noisy human behaviour).

How to improve a linear model

  1. Look at residuals first — patterns tell you what is missing.
  2. Feature engineering: log-transform skewed variables, polynomial terms or splines for curvature, interaction terms (\(x_1x_2\)) for effects that depend on each other, binning for thresholds.
  3. Handle outliers & leverage: investigate, cap/winsorise, or use Huber / RANSAC / quantile regression.
  4. Multicollinearity: drop or combine features with high VIF, or use Ridge.
  5. Many features / overfitting: Lasso or Elastic Net with CV-chosen α; feature selection.
  6. Heteroscedastic target (e.g., prices): model log(y) and back-transform (beware the retransformation bias).
  7. If relationships are fundamentally non-linear with interactions, move to tree ensembles — and use linear regression as the baseline.

Pros, cons and when to use

✅ Strengths

  • Fast, closed-form, scales well
  • Highly interpretable coefficients, inference (CIs, p-values)
  • Strong baseline; good extrapolation when the relationship really is linear
  • Low variance with enough data

❌ Weaknesses

  • High bias for non-linear relationships unless you engineer features
  • Sensitive to outliers and multicollinearity
  • Needs encoding of categoricals, no automatic interactions
  • Assumptions needed for valid inference

Use when you need explainability (pricing, econometrics, regulated settings), a baseline, or the signal is roughly additive. Avoid for complex interactions or when only raw predictive accuracy on tabular data matters (try gradient boosting).

Interview questions

What are the assumptions of linear regression?

Linearity in parameters; independence of errors (no autocorrelation); homoscedasticity (constant error variance); normality of errors (for inference); no perfect multicollinearity; exogeneity (errors uncorrelated with features / no omitted confounders). Mention which ones affect predictions (linearity, exogeneity for causal reading) vs inference (independence, homoscedasticity, normality).

What is homoscedasticity and how do you detect and fix heteroscedasticity?

Homoscedasticity = residual variance is the same at every level of the predictors. Heteroscedasticity shows up as a funnel in residuals-vs-fitted. Detect with that plot, the scale-location plot, or Breusch–Pagan / White tests. Consequences: coefficients remain unbiased, but OLS is no longer efficient and standard errors, t-stats, p-values and CIs are wrong. Fixes: transform y (log, Box-Cox, sqrt), Weighted Least Squares with weights ∝ 1/variance, or heteroscedasticity-consistent (HC3 / White) standard errors.

What is multicollinearity? How do you detect and handle it?

High correlation among predictors. It inflates the variance of coefficient estimates (unstable, sign flips, large SEs, insignificant individually but jointly significant) but does not hurt predictive accuracy much. Detect: correlation matrix, VIF (>5–10), condition number of X. Handle: drop one of the correlated features, combine them (ratio, average, PCA), collect more data, or use Ridge which stabilises coefficients.

What is VIF and how is it computed?

Variance Inflation Factor for feature j: regress \(x_j\) on all other features, take that \(R_j^2\), then \(\text{VIF}_j = 1/(1-R_j^2)\). It is the factor by which the variance of \(\hat\beta_j\) is inflated relative to uncorrelated features. VIF = 1 none, 5 → \(R^2_j\)=0.8, 10 → 0.9.

Derive the OLS closed-form solution.

Minimise \(\lVert y-X\beta\rVert^2 = y^Ty - 2\beta^TX^Ty + \beta^TX^TX\beta\). Gradient: \(-2X^Ty + 2X^TX\beta = 0\) ⇒ \(X^TX\beta=X^Ty\) ⇒ \(\hat\beta=(X^TX)^{-1}X^Ty\), valid when \(X^TX\) is invertible (full column rank). The Hessian \(2X^TX\) is positive semi-definite, so it is a global minimum.

When would you use gradient descent instead of the normal equation?

When p is large (inverting a p×p matrix is O(p³)), when n is huge or data doesn't fit in memory (mini-batch/SGD streams), for online learning, or when adding non-closed-form penalties (Lasso uses coordinate descent). Normal equation: no learning rate, no scaling needed, exact — fine for small/medium p.

Why do we minimise squared error rather than absolute error?

Squared error is differentiable everywhere and convex with a closed-form solution; it equals the MLE under Gaussian noise; it estimates the conditional mean; and it penalises large errors more. Absolute error (MAE/LAD) estimates the conditional median, is robust to outliers, corresponds to Laplace noise, but has no closed form (solved via linear programming) and a non-smooth gradient at 0.

Difference between R² and adjusted R²?

R² = 1 − RSS/TSS, the share of variance explained; it never decreases when features are added (on training data). Adjusted R² = 1 − (1 − R²)(n − 1)/(n − p − 1) penalises the number of predictors, increasing only if a new feature improves the fit more than expected by chance. Use adjusted R² (or better, CV error / AIC / BIC) to compare models with different numbers of features.

Can R² be negative?

On training data with an intercept, no (OLS is at least as good as the mean). On test data, or without an intercept, yes: it means the model predicts worse than a constant equal to the mean of y.

How do you interpret coefficients when y is log-transformed?

log(y) = β₀ + β₁x: a one-unit increase in x multiplies y by \(e^{\beta_1}\), ≈ a 100·β₁ % change for small β₁. log(y) ~ log(x): β₁ is an elasticity (1 % change in x → β₁ % change in y). y ~ log(x): a 1 % increase in x changes y by β₁/100 units.

What happens if you duplicate a feature (or duplicate all rows)?

Duplicate feature: perfect collinearity, \(X^TX\) singular; OLS has infinitely many solutions (the pseudo-inverse / sklearn splits the weight). Ridge splits it evenly. Duplicating all rows: coefficients unchanged, but standard errors shrink by √2 — falsely inflated confidence, a classic data-leakage-in-inference trap.

What are outliers, leverage points and influential points?

Outlier: unusual y given x (large residual). High leverage: unusual x (far from the feature mean; diagonal of the hat matrix \(H=X(X^TX)^{-1}X^T\)). Influential: removing it materially changes the fit — usually high leverage and large residual; measured by Cook's distance. OLS is sensitive because errors are squared.

What does the p-value of a coefficient mean?

The probability of observing a t-statistic at least as extreme as ours if the true coefficient were 0 (and assumptions hold). Small p → evidence that the feature has a non-zero association with y given the other features. It is not the probability that the coefficient is zero, and not a measure of effect size or causality.

What is omitted-variable bias?

If a variable z affects y and is correlated with an included x, leaving z out makes x's coefficient absorb z's effect: \(E[\hat\beta_x] = \beta_x + \beta_z\cdot\delta\), where δ is the slope from regressing z on x. It violates exogeneity, so coefficients are biased — no amount of data fixes it. Example: ice-cream sales vs drowning, omitted temperature.

How does linear regression handle categorical variables?

One-hot/dummy encode with k − 1 columns (drop a baseline) to avoid the dummy-variable trap when an intercept exists; each coefficient is the difference vs the baseline. For high cardinality consider target encoding (with CV to avoid leakage) or regularisation.

Do you need to scale features for linear regression?

Not for OLS predictions — the closed-form solution is scale-equivariant (coefficients just rescale). You do need scaling for gradient descent (faster, stable convergence), for regularised models (penalty treats all coefficients equally), and to compare coefficient magnitudes.

What if p > n?

\(X^TX\) is rank-deficient: infinitely many zero-training-error solutions, perfect overfit. Use regularisation (Ridge always has a unique solution, Lasso selects at most n features), dimensionality reduction (PCA regression, PLS), or feature selection.

Explain the bias–variance of OLS and why Ridge can beat it.

OLS is unbiased (under assumptions) but may have high variance with many / correlated features. Ridge introduces a small bias by shrinking coefficients, which can reduce variance by more, lowering expected test MSE. Gauss–Markov only says OLS is best among unbiased linear estimators.

How would you check if a linear model is appropriate for your data?

Scatter / pair plots, residuals vs fitted and vs each feature (no pattern), Q-Q plot, compare CV error with a flexible model (e.g., gradient boosting): if the flexible model is much better, important non-linearity/interactions are missing.

What is the hat matrix and what are its properties?

\(H = X(X^TX)^{-1}X^T\), it “puts the hat on y”: \(\hat y = Hy\). It is symmetric and idempotent (a projection), with trace = p + 1 (number of parameters). Diagonal elements \(h_{ii}\) are leverages; average leverage is (p+1)/n and points with \(h_{ii} > 2(p+1)/n\) are high-leverage.

Correlation vs regression coefficient?

Simple regression slope = \(r\cdot s_y/s_x\). Correlation is symmetric, unit-free, in [−1, 1]; the slope is directional (y on x ≠ x on y) and in units of y per unit of x. In simple regression, R² = r².

What is the difference between a confidence interval and a prediction interval?

A confidence interval covers the mean response \(E[y\mid x]\) — uncertainty only in the estimated line. A prediction interval covers a new individual observation — adds the irreducible noise σ², so it is always wider and does not shrink to zero with more data.
